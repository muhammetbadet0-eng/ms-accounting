MS ACCOUNTING V1.3 — بوابة العملاء والسحابة (تهيئة Firebase)

ما تمت إضافته:
- حقل بريد إلكتروني لكل عميل في سجل العميل.
- تسجيل دخول بالبريد وكلمة المرور عبر Firebase Authentication.
- بوابة العميل تعرض كشفه السحابي فقط (إجمالي المبيعات والمدفوع والمتبقي والحركات).
- إرسال طلب دفع مع طريقة الدفع وملاحظة وإرفاق صورة/PDF للإيصال.
- الطلب يبقى pending ولا يغيّر رصيد العميل. لا بد من مراجعة الإدارة وتسجيل التحصيل في البرنامج.
- زر مزامنة في حساب الإدارة يرفع كشوف العملاء الذين لديهم بريد إلكتروني.
- قواعد Firestore وStorage تمنع العميل من تعديل كشفه، وتسمح له بقراءة كشف البريد المطابق وإرسال طلباته الخاصة.

مهم: هذه النسخة هي تكامل جاهز للتهيئة، وليست خدمة سحابية مفعلة مسبقاً. يلزم إنشاء مشروع Firebase خاص بك وربط إعداداته قبل تسجيل الدخول أو رفع البيانات.

خطوات التفعيل:
1) أنشئ مشروعاً في https://console.firebase.google.com/
2) أضف Web App وانسخ إعداد firebaseConfig.
3) انسخ firebase-config.example.js وسمّ النسخة firebase-config.js، ثم ضع إعدادات مشروعك الحقيقية داخله. لا تضع كلمة مرور أو مفتاح خدمة Admin داخل هذا الملف.
4) في Firebase Authentication فعّل Email/Password.
5) أنشئ Firestore Database وطبّق محتوى firestore.rules من تبويب Rules.
6) أنشئ Storage وطبّق storage.rules من تبويب Rules.
7) أنشئ حساب الإدارة في Authentication، ثم امنحه custom claim admin=true باستخدام بيئة موثوقة Admin SDK (لا يمكن ضبطها بأمان من المتصفح). لا تستخدم حساب العميل كإدارة.
8) أنشئ حسابات العملاء في Authentication بالبريد الذي أدخلته في ملف العميل. استخدم بريداً مطابقاً تماماً لحقل البريد.
9) انشر مجلد MS_Accounting كاملاً على استضافة HTTPS (GitHub Pages مناسب). افتح الموقع من رابط HTTPS، وليس بالنقر المزدوج على index.html، لأن Firebase modules تتطلب استضافة.
10) سجّل الدخول بحساب الإدارة، واضغط «مزامنة جميع حسابات العملاء الآن». أضف البريد الإلكتروني لكل عميل أولاً.
11) يفتح العميل الموقع نفسه ويسجل الدخول ببريده وكلمة المرور؛ يستطيع مشاهدة كشفه وإرسال طلب دفع/إيصال.

أمان وقيود:
- العميل لا يستطيع تعديل كشف الحساب أو اعتماد طلبه بنفسه.
- قواعد Firestore وStorage موجودة في الملفات المرفقة ويجب نشرها قبل الاستخدام.
- منح admin=true يتطلب Admin SDK في بيئة موثوقة؛ لا تضع service account key داخل ملفات الموقع.
- رفع كشف العميل يتم عند ضغط زر المزامنة من حساب الإدارة. يجب الضغط عليه بعد تسجيل مبيعات/دفعات جديدة لنشر آخر الأرقام.
- ملفات الإيصالات في Firebase Storage، والروابط تظهر ضمن قائمة الطلبات الخاصة بالعميل.
- قبل اعتماد النظام للإنتاج، اختبره بحساب إدارة وحساب عميل تجريبيين، وتأكد أن العميل لا يستطيع قراءة بريد عميل آخر.
- خذ نسخة JSON احتياطية من البرنامج قبل التحديث.

النسخة المحلية الأصلية وبيانات localStorage لم تُحذف. المزامنة لا تستبدل النسخة المحلية.
